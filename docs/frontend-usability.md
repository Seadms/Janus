# Frontend usability test

Run the full local workspace with the Nucleo simulator. Let the simulator run for
at least a minute before starting. Use the simulator for every session so that
commands change only simulated readings.

Recruit at least five people who have never used Janus. Give each person an
operator account for the simulator and the local address. Start on the sign-in
page. Ask the person to complete these tasks without help:

1. Sign in.
2. Open the Nucleo device.
3. Tell the moderator the latest tilt reading and its unit.
4. Show the tilt readings for a recent time range.
5. Set the simulated motor speed to 25%, then show the confirmation.

Read the tasks verbatim. If a participant needs a hint, mark the task as assisted
and write down where they stopped. Restore the simulated motor with **Stop motor**
and sign out before starting the next session.
